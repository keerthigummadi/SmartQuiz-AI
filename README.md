AI-powered quiz generation platform for interactive learning
# 🧠 AI Quiz Generator

An AI-powered quiz generation platform that creates smart quizzes from user input topics using artificial intelligence.

---

# 🚀 Product Overview

The AI Quiz Generator helps students and learners instantly create quizzes on any topic. Users can select categories, generate questions, answer quizzes, and track performance.

This project supports:

- Quality Education (SDG 4)

# ⚙️ Installation Guide

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/AI-Quiz-Generator.git
```

## 2️⃣ Open Project Folder

```bash
cd AI-Quiz-Generator
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start Frontend

```bash
npm run dev
```

## 5️⃣ Start Backend

```bash
node server.js
```
